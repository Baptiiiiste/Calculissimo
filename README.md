# Calculissimo

## Lancement du projet

```bash
cd Calculissimo
cmake -S . -B build && cmake --build build && ./build/Calculissimo
```

## Fonctionnalités

- Choix de la difficulté (facile, moyen, difficile)
- Choix du mode de jeu (Entrainement, Chrono)
- Mascotte
- Système de monnaie
- Boutique pour acheter des éléments pour personnaliser la mascotte
- Sauvegarde de la progression du joueur (monnaie, éléments achetés)

## Intelligence artificielle

Utilisation de l'intelligence artificielle pour améliorer la partie frontend de l'application car mes connaissances avec Raylib sont limitées et je souhaitais tout de même avoir une application graphique et agréable à utiliser.
Utilisation principalement pour la partie visuelle de la boutique et pour affiner les menus.

Le reste du code a été écrit uniquement par moi-même.
